# Astra Assistant

Личный Android-ассистент с русским интерфейсом, локальной историей сообщений и возможностью позже подключить облачную ИИ-модель.

## Первый этап

- Android-приложение на Kotlin и Jetpack Compose.
- Локальное сохранение переписки через Room.
- Демонстрационный режим без API-ключа и расходов на запросы.
- Сборка APK через GitHub Actions.

## Сборка APK

1. Открой вкладку **Actions** в репозитории.
2. Выбери workflow **Build Android APK**.
3. Нажми **Run workflow**, если он не запустился после изменения файлов.
4. Открой завершённый запуск и скачай артефакт `astra-debug-apk`.

Это ранний прототип. Подключение OpenAI API и серверной части будет добавлено отдельным этапом. Не помещай секретные API-ключи в Android-приложение или репозиторий.

## Структура

- `android/` — Android-приложение.
- `.github/workflows/` — автоматическая сборка APK.
- `backend/` — будет добавлен на следующем этапе.
