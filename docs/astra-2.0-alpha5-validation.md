# Astra Preview 2.0.0-alpha.5 — проверка на устройстве

Изменения: защита от повторного подтверждения, проверка обработчика системного приложения и более точный статус отправки системных Intent. Alpha 5: `versionCode=32`.

## Перед установкой

- Только Preview (`com.astra.assistant.preview`), не стабильная Astra.
- Подписывать сборку локальным постоянным ключом Preview и запускать `bash scripts/check-preview-upgrade.sh APK` перед установкой.
- Не удалять приложение и не очищать данные. Никакого публичного релиза без разрешения.

## Проверка с участием владельца телефона

1. Открыть чат Astra и отправить «открой камеру». До подтверждения камера не должна запускаться; после подтверждения должен появиться экран камеры.
2. Отправить «открой будильник» и нажать «Отмена». Будильник не должен открыться из-за отменённой команды.
3. Отправить «открой телефон» и подтвердить. Должен открыться экран набора номера, **без совершения звонка**.
4. Быстро дважды коснуться кнопки подтверждения на одной команде. Не должно возникнуть двух независимых действий или двух записей о результате.
5. Проверить «открой настройки», «назад», «покажи возможности». Команды Accessibility должны по-прежнему запрашивать подтверждение.
6. Убедиться, что история чата и настройки Preview сохранились, а Termux не нужен для нативных действий.

## Границы проверки

`startActivity()` сообщает только, что Android принял запрос на запуск; без наблюдения за UI нет гарантии, что экран действительно открылся. Тесты JVM и GitHub Actions не заменяют ручную проверку на iQOO/OriginOS. Внешние команды из ответа ИИ не исполняются: разрешены только отдельно проверенные фразы, набранные пользователем.
