# Голосовое управление в Astra Preview

## Целевой сценарий

Владелец вызывает установленный ChatGPT системным жестом на разблокированном телефоне. Фразы «открой настройки» и «открой Telegram» должны сразу открывать нужный экран. В обычном использовании пользователь не запускает Termux, не диктует имя инструмента и не подтверждает одну и ту же команду повторно.

Для Telegram различаем открытие конкретного чата, подготовку текста и доставку сообщения. При совпадении имён уточняем адресата. Успех отправки требует подтверждения от Telegram. Открытие чата или передача текста в поле ввода подтверждают только соответствующий шаг.

Первый сквозной тест — «открой настройки»: начать в ChatGPT по жесту и увидеть системные настройки при остановленном Termux. Для нативного пути проверить у установленного ChatGPT разрешение на вызов Android AppFunctions, затем фактический вызов тестовой функции и возможность открыть экран на iQOO. Наличие разрешения само по себе не подтверждает интеграцию. Альтернативный транспорт — личный плагин ChatGPT с привязкой к нативному клиенту Astra. Обязательные подтверждения самого ChatGPT зависят от действия и платформы.

Подтверждение в демонстрационной Alpha 10 защищает открытый Android-приёмник, которому могут отправлять предложения другие приложения. Автоматическое выполнение допустимо проектировать отдельно для проверенного источника. Голосовая фраза сама по себе не устанавливает происхождение входящей команды.

## Проверка прямого вызова на iQOO от 18 ноября 2026

На Android 16 (API 36) системная служба `app_function` зарегистрирована. Для пользователя 0 роль `android.app.role.ASSISTANT` и компонент голосового помощника принадлежат установленному ChatGPT 1.2026.314. Установлена Astra Preview 2.0.0-alpha.10.

Команда `dumpsys package check-permission android.permission.EXECUTE_APP_FUNCTIONS com.openai.chatgpt 0` вернула `-1` (отказ). Проверка `android.permission.INTERNET` тем же способом вернула `0` (разрешено). В списке запрошенных разрешений ChatGPT отсутствует `EXECUTE_APP_FUNCTIONS`. Следовательно, эта установка ChatGPT не может вызвать AppFunction Astra напрямую. При смене версии ChatGPT результат можно проверить повторно.

Для маршрута с личным плагином остаются два отдельных критерия: получить запрос из Live на привязанном телефоне при остановленном Termux и открыть настройки, когда на экране ещё ChatGPT. Оба требуют проверки на устройстве.

## Точка продолжения на 18 ноября 2026

Влад решил попробовать личный плагин ChatGPT Live для Astra. На момент паузы проверены требования к подключению. Реализация MCP-сервера и нативного приёма команд в Astra ещё впереди. Плагин не зарегистрирован, сквозной тест не проводился. По словам Влада, свободного сервиса с постоянным HTTPS-адресом на Altare, скорее всего, нет. Хостинг пока не выбран.

Продолжить с прототипа одной команды «открой настройки» и привязки к телефону владельца. Затем выбрать доступное размещение, подключить личный плагин и проверить на iQOO системный жест при остановленном Termux. К Telegram перейти после успешного открытия настроек. Публичный релиз требует отдельного разрешения владельца.

## Эксперимент Alpha 10 из ChatGPT Live

На телефоне открой Astra Preview → Инструменты → «Разрешить внешние голосовые команды». В голосовом разговоре ChatGPT Live должен быть доступен подключённый Desktop Commander с устройством Termux. Для первого теста скажи «Через Desktop Commander выполни на телефоне astra-voice wifi». Если короткая команда не в PATH, используй `~/astra-assistant/scripts/astra-voice wifi`.

| Аргумент | Что предложит открыть Astra |
| --- | --- |
| wifi | Настройки Wi-Fi |
| display | Настройки экрана |
| sound | Настройки звука |
| settings | Настройки Android |
| camera | Камеру |
| alarms | Будильники |

Команда передаёт Android один идентификатор, затем просит показать Astra Preview. Если прошивка оставила приложение в фоне, открой Astra вручную. На экране проверь действие и нажми «Открыть» или «Отмена». Запуск команды в Termux сам по себе не подтверждает доставку или открытие нужного экрана.

Внешние приложения тоже могут предложить один из этих шести пунктов при включённой функции. В карточке указан пункт назначения. Astra держит одно предложение, новое заменяет предыдущее. Через две минуты оно теряет силу. При отключении функции ожидающее предложение удаляется. Права Accessibility и ADB для этого пути не требуются.

## Из чата Astra

Нажми микрофон, произнеси «Астра, открой настройки» и проверь черновик. После отправки Astra предложит открыть настройки. Обычный вопрос обрабатывается через настроенное подключение чата. Распознаватель выбирает Android. Astra предпочитает автономное распознавание, доступность зависит от системной службы и языковых пакетов.
